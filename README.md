# 公務人員考試歷屆試題複習系統（中國科技大學 管理學院）

純靜態網頁，掛在 GitHub Pages，學生開網址即用，免登入、免後端。

## 目前功能

| 需求 | 實作 |
|---|---|
| 學生透過網頁連線 | GitHub Pages 網址 |
| 依類科選科目 | 設定畫面依「考試等別 → 類科 → 應試科目」三層選擇；選定類科後，列出該類科在此等別題庫已收錄的科目（含題數與年度），點選即可切換 |
| 亂數出題 | 隨機出題／依考點練習／錯題重練；可篩年度、題數；同一輪不重複 |
| 網頁輸入答案 | 選擇題點選選項；可選每題 72 或 45 秒倒數，時間到自動算未答 |
| 送出後評分並給完整答案建議 | 立即顯示對錯、得分、正確答案與詳解；支援考選部「更正答案」與「一律給分」 |
| 接續練習或停止 | 下一題／結束並檢視紀錄／繼續練習；關掉網頁後可「接續上次紀錄」 |
| 依作答給意見與建議 | 單題、每輪、累計、申論題四個層次的個人化回饋，見下方「意見與建議」 |
| 複習輔助 | 錯題本、各考點答對率、複製文字紀錄、列印或存成 PDF、備份與匯入紀錄 |

紀錄只存在學生自己的瀏覽器，不會傳到任何伺服器。

## 檔案

```
index.html        前端（HTML + CSS + JS，無外部套件）
core.js           出題、評分、統計邏輯（可用 Node 單獨測試）
data/bank.json    題庫（選擇題）
data/essays.json  申論題：題目、參考答案、評分細目
docs/             申論題參考答案的可讀版本（執行 node tools/make_docs.js 由 essays.json 產生）
tools/make_docs.js  產生 docs/ 內的參考答案文件
tests/            test_core.js（選擇題與出題邏輯）、test_essay.js（申論題）、test_feedback.js（意見與建議）
.nojekyll         讓 GitHub Pages 原樣提供檔案
```

## 部署到 GitHub Pages

1. 在 GitHub 建立倉庫（Pages 在免費方案只支援公開倉庫，題庫與詳解會是公開的）。
2. 把本資料夾的所有檔案放進倉庫根目錄（網頁介面：Add file → Upload files；或 `git push`）。
3. Settings → Pages → Source 選 Deploy from a branch，Branch 選 main、資料夾選 / (root)，按 Save。
4. 1 至 2 分鐘後網址為 `https://<帳號或組織>.github.io/<倉庫名>/`。

本機測試：在資料夾執行 `python3 -m http.server 8000`，開 http://localhost:8000。不要直接雙擊 index.html（瀏覽器會擋住讀取題庫檔）。

## 類科選單

設定畫面的選單順序為「考試等別 → 類科 → 應試科目」。類科與科目的對應完全由題庫資料自動產生：

- 類科清單 ＝ 該考試等別下，`bank.json` 與 `essays.json` 每一題 `categories` 欄位出現過的類科。
- 科目清單 ＝ 該等別、該類科 `categories` 有列入的科目。選了「經建行政」只會看到經濟學、公共經濟學等該類科應考的科目。
- 選定類科後，選單下方會列出科目清單，附選擇題／申論題題數與收錄年度。
- 類科也會篩選題目：例如「金融保險」選「經濟學」只出 113、114 年（115 年金融保險改考「經濟學與貨幣銀行學」）。
- 新增科目或類科不需改程式，只要題目的 `categories` 填正確。清單只含題庫已收錄的科目，國文、法學知識等未收錄的科目不會出現。
- `core.js` 的 `buildPool` 新增 `category` 篩選條件；`tests/test_core.js` 有對應測試。

## 申論題練習與評分

流程：設定畫面選到有申論題的科目（見上表；公共經濟學只有申論題，選到時不會顯示選擇題練習區）→ 出現「申論題練習」面板 → 選題作答 → 每小題各自送出評分。

評分分兩步，**第二步由學生確認**：

1. **系統初判**：把學生的答案做文字正規化（全形轉半形、`²` 轉 `2`、去空白與括號、統一減號），再比對每個「評分細目」的關鍵字／公式寫法（正規表示式）。`d²/(2b)`、`d^2 / 2b`、`\frac{d^2}{2b}` 會被視為同一種寫法。
2. **學生確認**：初判結果預填在各細目的下拉選單（0、0.5、1…至該細目配分），學生對照參考答案自行調整，總分即時更新。

**計算題的數值比對（工程經濟學等）**：評分細目除了 `patterns` 之外，可以加 `nums`，系統會從答案文字抽出所有數字（支援全形、千分位 `1,006.07`、負號、`萬`／`億` 單位，`1,006 萬` 會同時視為 1006 與 10,060,000），只要有數字落在目標值的容許誤差內就算符合。預設容許誤差 0.2%，可用 `tol` 調整。這樣查表取四位小數造成的誤差（例如以 0.0802 代替 0.080243）仍會判對，但算錯的數字（例如每年只用當年利率折現得到 5,190 萬）不會得分。數值比對以絕對值進行，`-1,372,183` 與 `1,372,183` 視為相同。

重要限制：系統只認關鍵字與寫法，**看不懂推導是否正確**。學生用不同寫法會漏判，只提到名詞但推導錯誤也可能誤判；計算題只核對數字，**不檢查列式過程**（數字蒙對或過程錯誤但結果碰巧相同，也會得分），所以最後分數一定由學生確認，且分數僅供自我檢視，不等於閱卷結果。若需要語意層級的批改，必須人工或另接後端／AI 服務（靜態網頁無法保護金鑰，本專案不做）。

草稿（作答文字、評分）自動存在瀏覽器，關掉網頁再開可接續；按「儲存本題成績並結束」才會寫入成績紀錄。備份檔（版本 2）會一併包含申論題草稿與成績，舊版備份仍可匯入。

### 計算題與開放式設計題

- 題目可加 `note`（作答提醒，顯示在題目下方）；小題可加 `"calc": true`（計算題）。計算題的 `patterns` 比對的是**關鍵數值與列式**。注意正規化會去掉逗號、句點、`$`、空白、括號與 `×`，所以 `7,726.56` 會變成 `772656`、`0.5 × 100` 會變成 `05100`，pattern 要照這個寫法；數值建議用 `7(726|727)` 這類寫法容許四捨五入。
- 標 `calc` 的小題，若有細目沒得分，意見與建議會多一則「數值只差四捨五入可手動調整、列式正確仍可得部分分」的提醒。
- 開放式設計題（例如產業經濟學第 4 題（一）「自行設計需求函數」）系統只能檢查結構（兩條需求式、另一財貨價格係數為負），是否合理仍由學生對照參考答案確認。
- 工程經濟學為計算題，真實考試可使用計算機；農業保險的規則（保費補助比例、理賠門檻、定額理賠金額）會逐年調整，參考答案以考試當年與近年農業部公告為準。
### 要求「繪圖」的題目

靜態網頁沒有畫圖功能，系統無法批改圖形。遇到題目含「繪圖、作圖、圖形、畫出、圖示、展開式」等字樣時，作答畫面會提示學生改用文字描述：標明橫軸縱軸、各曲線、交點，以及哪一塊面積是消費者剩餘、生產者剩餘或無謂損失。評分細目也是針對這種文字描述設計（例如「無謂損失為 b + d 兩個三角形」）。學生仍應在紙上實際畫圖練習。

### 新增申論題

在 `data/essays.json` 的 `essays` 陣列加入題目。載入時會檢查格式，有誤時申論題面板不會出現，並在瀏覽器主控台印出原因。

```json
{
  "id": "115-g3econ-E1",
  "year_roc": 115, "exam": "公務人員高等考試三級考試", "categories": ["統計", "經建行政"],
  "subject": "經濟學", "question_no": 1, "points": 25, "area": "個體經濟",
  "tags": ["外部性"],
  "question": "題目共同敘述（允許少量 HTML）",
  "parts": [
    {
      "id": "1", "label": "（一）", "points": 5,
      "question": "小題題目",
      "model_answer": "參考答案（允許 <br>、<b>、<sub>、<sup>）",
      "rubric": [
        { "id": "r1", "label": "得分點說明", "points": 1.5,
          "patterns": ["a-c-d/b", "社會邊際成本.{0,12}c\\+d"], "min": 1, "hint": "選填，顯示在細目下方" }
      ],
      "pitfalls": "常見錯誤（選填）"
    }
  ],
  "source": "出處"
}
```

- 各小題 `points` 加總必須等於 `points`；各細目 `points` 加總必須等於該小題 `points`。
- `patterns` 是**對正規化後文字**比對的 JavaScript 正規表示式字串（JSON 內反斜線要寫成 `\\`）。因為括號、空白、`*`、`^`、`_` 與句點都已被去掉，`Q*=(a-c-d)/b` 會變成 `q=a-c-d/b`。字母一律小寫。
- `nums`（選填，計算題用）：`[{ "v": 5131.62, "tol": 0.001 }]`，`v` 為目標值，`tol` 為相對容許誤差（預設 0.002），也可用 `abs` 設絕對容許誤差。每個 `nums` 項目與每條 pattern 一樣，都算作「符合一條」，所以 `min` 可混用兩者。一個細目至少要有 `patterns` 或 `nums`。小數值（例如 0.909）要自己確認不會被題目文字或其他數字誤中。若題意有兩種合理解讀（如工程經濟學第 2 題存款 21 筆或 20 筆），可把兩個答案都放進 `nums`，`min: 1`。
- `min`：至少要符合幾條 pattern（或 nums）才給滿分；符合但不足時按比例給分（進位到 0.5）。概念型細目建議 `min: 2`，避免只提到一個名詞就拿滿分。
- 小題可加兩個選填旗標：`"figure": true`（本小題要求繪圖）、`"numeric": true`（本小題是計算題）。有旗標時，「意見與建議」會檢查學生答案有沒有說明圖形的軸與曲線、有沒有寫出數字，並給對應提醒。
- 小題另有 `"calc": true`（計算題，見上方「計算題與開放式設計題」）；`calc` 與 `numeric` 都是計算題旗標，`calc` 會在細目沒得分時提醒數值與列式，`numeric` 會依答案有無數字給提醒，兩者可並用。
- 小題另有三個選填欄位，供翻譯與作文題使用（觀光英語、觀光日語）：`"lang": "zh" | "ja" | "en"`（要求的作答語言，答案用錯語言時「意見與建議」會提醒；專門名詞可保留原文）、`"limit": { "unit": "word" | "char", "min": 250, "max": 300 }`（字數範圍；`word` 數英文單字，`char` 數不含空白與換行的字元；作答區會即時顯示字數，超過上限變紅，回饋會提醒超出或偏少，字數不到下限一半時初判分數按字數比例調降）、`"minChars": 150`（覆寫預設的「配分 × 12 字」偏少提醒門檻）。英文與日文題的 `patterns` 同樣對**正規化後（已去空白）**的文字比對，所以英文片語要寫成 `inconclusion`、`suchas`，不能含空格。
- 申論題 id 命名：`<年度>-g3<科目代碼>-E<題號>`，例如 `114-g3tre-E1`（運輸經濟學）、`114-g3agr-E1`（農業經濟學）、`114-g3eng-E1`（工程經濟學）、`115-g3io-E1`（產業經濟學）、`115-g3ee-E1`（115 年工程經濟學）、`115-g3te-E1`（115 年運輸經濟學）、`114-g3ie-E1`（114 年產業經濟學）、`114-g3pe-E1`（公共經濟學）、`114-g3fin-E1`（經濟學與財政學概論）、`114-g3econ-E1`（經濟學）、`113-g3io-E1`（113 年產業經濟學）、`113-g3te-E1`（113 年運輸經濟學）、`113-g3fin-E1`、`113-g3econ-E1`、`113-g3pe-E1`（113 年各科）、`113-g3agr-E1`、`113-g3eng-E1`（113 年農業、工程經濟學）、`113-g3pft-E1`、`113-g3pfa-E1`（113 年財政學財稅行政、會計）、`114-g3pf-E1`、`114-g3acc-E1`（114 年財政學財稅行政、會計）、`115-g3pf-E1`、`115-g3pfa-E1`（115 年財政學財稅行政、會計審計）；`114-g3civ-E1`（114 年高考三級民法，財稅行政、財稅法務）、`114-pcivil-E1`（114 年普考民法概要，財稅行政）、`114-g3ftc-E1`（114 年高考三級民法，公平交易管理）；`114-g3land-E1`（114 年地政高考三級民法）、`114-pland-E1`（114 年地政普考民法物權編概要）；`114-g3civj-E1`（114 年高考三級民法，司法行政）、`114-g3civl-E1`（114 年高考三級民法，法制、智慧財產行政）；`114-g3hr-E1`（114 年高考三級戶政）、`114-phh-E1`（114 年普考戶政民法）。
